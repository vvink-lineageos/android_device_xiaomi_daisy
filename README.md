# android_device_xiaomi_daisy

Device tree for Xiaomi Mi A2 Lite (daisy).

## Device specs

| Property | Value |
|---|---|
| SoC | Qualcomm Snapdragon 625 (MSM8953) |
| RAM | 3/4 GB LPDDR3 |
| Storage | 32/64 GB eMMC |
| Display | 5.84" IPS LCD, 1080x2280 |
| Battery | 4000 mAh |
| Android | 8.1 (stock), AndroidOne |

## Based on

- [android_device_xiaomi_msm8953-common](https://gitlab.vx64.org/lineageos/android_device_xiaomi_msm8953-common) — SoC common tree
- Reference device: **tissot** (Xiaomi Mi A1) — same SoC, same AndroidOne family

## LineageOS target

lineage-21

## Status

Work in progress — device tree being developed with adevtools.
